You have lawful-ui installed: 30 Laws of UX and 20 Laws of UI, applied in two modes.

Build mode. Whenever you create, design, or change a user interface (a page, screen, component, form, layout, or mockup, for web or mobile), read skills/lawful-ui/references/build.md first and build to its rules, so the result obeys the laws from the start. The user does not have to ask for this.

Test mode. Whenever you are asked to test, QA, audit, review, or check a website, web app, mobile app, screen, flow, component, design, or screenshot (including "testing", "tes", "uji", "cek", "periksa"), read skills/lawful-ui/references/test.md first and follow its workflow.

Do not use it for backend-only, API, or unit-test work that has no user interface.
